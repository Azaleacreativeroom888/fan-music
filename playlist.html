TOUGH BOY / Tomcat

イントロ→Aメロ→Bメロ→サビ……そして最後にアウトロが来る。令和にはない教科書のような完成された曲。テンション上がるいい曲。

🎵
Groovy! / 広瀬香美

カードキャプターさくらのエンディングだった。広瀬香美で一番好きな曲。ちょっと落ち込んだときにいい。

🎵
ロマンスの神様 / 広瀬香美

可愛い曲だと思ってる。天気が良い日に聞きたい。

🎵
オトノケ / Creepy Nuts

まじで最高。アニメのオープニングとしてもワクワクするし最高。この曲と合わさったアニメの映像も最高。

🎵
Beat It / マイケル・ジャクソン

マイケル・ジャクソンの代名詞といえばBeat It！ ミュージックビデオのマイケルのダンスが上手すぎる。羽生えてるのかってくらい軽快。

🎵
Thriller / マイケル・ジャクソン

リズムを刻みたくなるキャッチーな曲。最高。

🎵
ウイマーマ・サーガ / しぐれうい

とんでもない曲に出会ってしまった。この曲を歌えるのはしぐれういだけだと思う。

🎵
JANE DO / 米津玄師 / 宇多田ヒカル

楽しいだけがエンタメじゃないなって思うのがこの曲。悲しいけど、すごく心地のいい。ちょっと涼しい雨の日に聴きたい。
